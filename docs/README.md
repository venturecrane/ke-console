# KE Console Documentation

Complete documentation index for the Kid Expenses (KE) venture. KE is a co-parent expense tracking application built on Next.js 16, Cloudflare Workers, D1, Clerk, and Stripe.

## Directories

| Directory                        | Description                                                                              |
| -------------------------------- | ---------------------------------------------------------------------------------------- |
| [adr/](./adr/index.md)           | Architecture Decision Records - significant technical decisions and implementation plans |
| [agents/](./agents/index.md)     | Multi-agent team personas and wave execution plans for backlog sprints                   |
| [design/](./design/index.md)     | Design charter, component system, status semantics, and screen priorities                |
| [handoffs/](./handoffs/index.md) | Session handoff records populated by `/eos` and consumed by `/sos`                       |
| [planning/](./planning/index.md) | Weekly sprint plans and issue targeting                                                  |
| [pm/](./pm/index.md)             | Product Requirements Document, database schema, and PRD contribution records             |
| [process/](./process/index.md)   | Project workflows, branching conventions, and operational processes                      |
| [product/](./product/index.md)   | Product rules - balance logic and permission policy constraints                          |
